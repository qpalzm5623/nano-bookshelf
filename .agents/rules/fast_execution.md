# Fast & Lean Execution Rules (크레딧 절약 및 고속 작업 원칙)

## 1. 브라우저 서브에이전트(browser_subagent) 사용 제한
- **사용자의 명시적 요청이 없는 한 `browser_subagent`를 자동 실행하지 않는다.**
- 사용자가 "화면 확인해줘", "브라우저로 테스트해봐", "캡처해줘"라고 명시한 경우에만 1회 제한적으로 실행한다.
- 단순 UI 수정(셀렉트 박스, 버튼, 스타일, 문구 변경 등)이나 비즈니스 로직 수정 시 브라우저 서브에이전트를 띄워 크레딧/토큰을 낭비하지 않는다.

## 2. 최소 도구 호출 및 직접 수정 원칙
- 코드는 `replace_file_content` 또는 `multi_replace_file_content`로 정확하고 신속하게 한 번에 수정한다.
- 불필요한 백그라운드 스크립트 실행, PHP 서버 재시작, 파워쉘 스크립트 남발을 금지한다.
- 검증은 파일 내용 확인(`view_file`) 수준에서 가볍게 마치고 즉시 완료를 보고한다.

## 3. 크레딧 및 응답 속도 최우선
- 사용자의 작업 속도를 늦추거나 크레딧을 대량 소모하는 과도한 반복 검증 루프를 절대 만들지 않는다.
- 수정 사항이 발생하면 즉시 코드를 반영하고, [결론] -> [코드] -> [상세 설명] 순서로 간결하게 전달한다.
